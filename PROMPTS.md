# PROMPTS.md

These are the prompts I would use with an AI coding assistant to recreate and extend the experiment portfolio. They are written as implementation prompts rather than copied from the reference repository.

## Master prompt

> Build an original data-science experiment as a self-contained Streamlit app. Use deterministic synthetic data when a public dataset would require a network download. Show the data-generation assumptions, preprocessing, model, validation method, metrics, and at least one interactive UX element. Favor leakage-safe evaluation and make the app runnable with one command.
